# Fixtures room: test colour pairs and brand data

One job: hold the input data the checker is tested against.

## Inputs

- `fixtures/clean.json`, `fixtures/exempt.json`, `fixtures/violating.json` — hand-built pass/fail/
  exempt colour-pair sets.
- `fixtures/brands/` — per-brand palettes; generated by `fixtures/build_brand_fixtures.py`.
- Missing input: a new brand with no source palette is not fabricated.

## Process

1. Add or edit colour pairs in the matching JSON file by expected outcome (clean/exempt/violating).
2. For brand fixtures, run `python3 fixtures/build_brand_fixtures.py` to regenerate `brands/`.
3. Re-run `python3 check.py` so the new fixtures are exercised.

## Outputs

- Updated `fixtures/*.json`, `fixtures/brands/*`.

## Human check

Alex confirms a new "violating" pair actually fails WCAG contrast math independently. Pass: the
checker's verdict matches. Fail: fixture is wrong, not the checker — fix the fixture.
